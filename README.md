# Fin User 🚀

> Controle seu dinheiro de forma simples, sem aquela chatice de planilha.

## 💡 O que é o Fin User?

O Fin User é uma aplicação web de organização financeira pessoal voltada para jovens que estão começando a ganhar dinheiro — estagiários, pessoas no primeiro emprego e freelancers iniciantes.

A ideia é simples: te ajudar a entender para onde seu dinheiro vai, sem complicação.

## 🎯 Funcionalidades

- 💰 Cadastro de renda (CLT, Freela, Estágio)
- 💸 Registro de despesas mensais
- 💳 Controle de dívidas
- 📈 Acompanhamento de investimentos
- 🎯 Metas financeiras com progresso
- 📊 Score financeiro (em breve)
- 🤖 FinBot assistente virtual (em breve)

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3 *(em desenvolvimento)*
- JavaScript *(em desenvolvimento)*
